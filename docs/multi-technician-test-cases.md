## 测试环境与约定

- A、B、C：同店有效维修工；S：服务顾问；W：仓管；I：独立检验员；X：跨店或未分配员工。
- 默认工单含 P1→A、P2→B，已接单且项目维修中；每个用例独立构造数据。
- 集成测试只使用本机 PostgreSQL，新建唯一名称临时库、应用迁移、结束删除；通知 mock，不调用生产润丰写入。
- 断言不仅检查操作返回，还检查其他人的项目未变化、版本、负责人、暂停、提检人及完成时间；数据库用例检查重新读取、事件、通知、照片归属、写回任务。
- P0：权限、数据隔离、错误完结或重复写入；P1：正常业务无法继续或状态错误。

自动化定位：`I` = `test/individualRepair.test.mjs`；`D` = `test/dispatch.integration.test.mjs`；`P` = `test/projectDispatch.test.mjs`；`E` = `test/repairItemEditing.test.mjs`；`R` = `test/repairReview.test.mjs`；`T` = `test/dispatchTechnicians.test.mjs`；`W` = `test/repairWriteback.test.mjs`；`N` = `test/repairRounds.test.mjs`。下表“通过”指对应自动化断言通过，不代表钉钉真机通过。
