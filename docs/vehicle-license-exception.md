# 新车行驶证缺失备案

新车默认仍须上传行驶证。公司系统确认车辆为新车后，服务顾问或门店管理员可在开单页选择“本次无法提供行驶证”，填写1至1000字说明。确认时保存当前草稿并单独办理备案；提交说明无需等待管理员审批，其他必填项及接车照片要求不变。

备案保存在服务端独立表中，记录委托单、车牌、VIN、说明、实际操作人和时间。客户端直接传入的备案字段不会生效；新建委托单不能继承已有备案，变更车牌或VIN后原备案不再满足签字条件。已锁定委托单不能新增或修改备案。相同请求重试或重复提交相同内容不重复通知。

后台通知本店所有启用的“门店管理员”。正式模式分页读取钉钉角色成员并绑定账号，沿用单门店约定导入尚未登录的管理员，保留已有门店归属和停用状态。mock 模式使用本店开发管理员，不向钉钉发送消息。消息包含说明、车牌、VIN、门店、委托单号、车主／单位、服务顾问和备案人，点击进入 `?workOrder=<委托单ID>` 对应的委托单详情。

通知在独立持久化队列处理，不依赖已签字或已生成派工任务。每位管理员单独记录受理、成功、失败和结果未知；明确的临时错误有界重试，发送结果未知不会盲目重发。详情与编辑页保留备案说明和通知状态，失败或结果未知可据此人工核对。通知链接仍需正常钉钉登录及当前门店访问权限，不包含登录令牌。

部署前运行 `npm run migrate` 应用 `202610150002_vehicle_license_exceptions.sql`。已有迁移未改动。
