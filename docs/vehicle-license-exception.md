# 新车行驶证缺失备案

新车默认仍须上传行驶证。公司系统确认车辆为新车后，服务顾问或门店管理员可在开单页选择“本次无法提供行驶证”，填写1至1000字说明。确认时保存当前草稿并单独办理备案；提交说明无需等待管理员审批，其他必填项及接车照片要求不变。

备案保存在服务端独立表中，记录委托单、车牌、VIN、说明、实际操作人和时间。客户端直接传入的备案字段不会生效；新建委托单不能继承已有备案，变更车牌或VIN后原备案不再满足签字条件。已锁定委托单不能新增或修改备案。相同请求重试或重复提交相同内容不会重复备案。

行驶证缺失备案不再发送钉钉工作通知。新备案直接记录为通知停用，不创建管理员收件记录，不读取管理员名单，不启动通知轮询；备案和审计仍保存，签字放行规则保持不变。

历史尚未发送的通知由新增迁移标记为停用；已经受理、成功、失败或结果未知的投递记录保持真实状态。有历史投递时，详情可按需查看“历史通知记录”，受理／未知且满足查询条件的记录仍可手动核对。新备案不显示“管理员通知待处理”，也不显示空通知面板。历史通知链接仍需正常钉钉登录及当前门店访问权限，不包含登录令牌。

部署前运行 `npm run migrate`，需包含原始备案迁移、手动查询快照迁移 `202611110001_manual_notification_results.sql` 及停推迁移 `202611110002_suppressed_notification_kinds.sql`；不修改已应用迁移。

验证：`npm run check`；显式设置本地 `LICENSE_EXCEPTION_TEST_ADMIN_URL` 运行 `test/vehicleLicenseException.integration.test.mjs`，该测试独立创建并删除测试数据库，不修改应用工单。
