# 公司车辆保险

车辆管理支持手工编辑保险生效日、到期日及承保明细，或上传公司车辆承保明细 `.xlsx`。门店管理员和服务顾问均可修改、启停车辆及导入，范围为本店车辆；出车审批仍仅限门店管理员。保险到期提醒发送给本店服务顾问和门店管理员，见下文。

## Excel 导入

点击“导入车辆及保险 Excel”，选择原表，预览后点“确认更新”。以“新车牌号”匹配本店车辆，匹配到则更新车型及保险明细，未匹配则新建。已有品牌、启停状态和车辆 ID 保留，表外车辆不删除；新建车辆的品牌取车型列，之后可人工完善。原车号只作为历史备注，不用于自动合并车辆，避免原车号中多个车牌串造成误匹配。

保留列：原车号、新车牌号、车型、登记及年审时间、保险终保时间、车辆状况、车辆使用部门、产权归属、投保付款单位、承保公司。年审列保留原始文本，不猜测不规范日期。保险列须含完整起止日期，例如 `2026.9.3-2027.9.2`。

单文件最多 3 MB、500 条，展开上限 16 MB。空行忽略，重复车牌、日期无效、缺少要求的列都会报错。保存使用整批事务；重复上传更新同一车辆，不重复建车。只把上传内容作为数据读取，不执行表内公式、宏或指令。

## 出车及提醒

按北京时间自然日判断：到期当天仍有效，次日过期。无完整保险日期、未生效或已到期均禁止申请及批准／确认出车，最终检查在服务端车辆行锁内进行；已出车可以正常还车。

2026-11-15 恢复保险钉钉工作通知，仅在北京时间距离到期恰好 7 天、1 天时提醒本店启用的服务顾问和门店管理员。双岗位同一员工只收一份；每辆车、到期日、节点、接收人去重。30 天、到期当天及过期提醒不恢复；错过节点不补发。

后台启动时扫描，之后每小时扫描一次，每分钟最多处理 10 条；同门店岗位名单每次扫描只同步一次。发送前复查车辆启用状态、到期日、接收人岗位及门店；续保、停用或撤权后取消旧消息。已受理或发送结果未知不自动重发。全局 DISPATCH_NOTIFICATION_MODE=disabled 时不扫描、不发送。

历史 suppressed 中从未提交钉钉的 7/1 天记录，仅在当前仍到达该节点时重新入队；已发送/已受理/未知等历史不重发。车辆卡片的保险通知记录模块不恢复。无新迁移或客户端轮询，复用现有保险日期索引和通知唯一约束。

## 发布

先应用 `202611100002_company_vehicle_insurance.sql`，再发布服务和前端；迁移仅新增列、通知表和索引，不虚构旧车辆保险。上线后在车辆管理导入原表，尚未录入保险的车暂不能出车。保留原车牌历史及用车关联。无需变更既有用车申请、审批或收车接口路径。
