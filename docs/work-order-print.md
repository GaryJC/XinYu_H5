# 委托单打印

在“归档查询”打开“委托单详情”，点击“打印委托单”，在打印设置中确认或修改进厂日期，再生成预览。手机预览会自动准备单页 PDF，准备完成后点击“发送到”调用系统文件分享，可发送到支持的应用或从系统菜单保存、打印。电脑可直接点击“打印”，也可以“导出 PDF”。进厂日期的修改仅作用于本次打印，不回写委托单。建议使用电脑浏览器，在系统打印窗口选择 A4 纵向；可选择实体打印机或保存为 PDF。手机流程生成实际单页 PDF，不依赖 WebView 的 `window.print()`。PDF 在浏览器本地生成，不上传到额外服务；系统文件分享能力由手机客户端支持情况决定；不支持时显示提示。详情和打印弹窗的底部操作区按 `safe-area-inset-bottom` 预留空间，正文独立滚动。

打印版按提供的《机动车修理委托书》纸质模板重建，使用当前详情中已保存的车辆、客户、接车检查、故障、维修项目、费用、顾问及门店信息。OCR 结果应先保存到委托单，打印不会另外读取未保存的识别结果。

客户手写签名放在“用户确认”处，优先使用 `signatures` 中客户签字关联的文件 ID；只有旧数据缺少关联且仅有一张签名图片时，才使用该唯一图片。签名缺失或加载失败时不能打印已签字委托单，避免生成漏签版本；未签字委托单标注“未签字”。“用户接车确认”栏已移除，服务顾问、总检验员栏保留。

打印固定为一张 A4，常规记录保留九行维修项目；清单或文字较长时整体缩放到一页，完整保留所有项目、确认文字和签名。清单极长时字体会相应缩小。零工费显示为空白。打印不显示委托单号、开工/完工时间列、旧件处置、费用说明和费用备注；页面自行保留内容边距，关闭浏览器默认页眉页脚的可打印区域。不输出来源照片的纸张颜色、扫描水印和复写联标记。物品勾选仅表示已登记的随车物品，不推断功能正常与否；轮胎深度、外观损伤坐标等未采集数据不会自动填写。

打印使用随应用部署的 Noto Serif SC 常规和粗体字体，生成文件前等待所需字符字体及签名加载完成，避免设备字体替换或文字自动放大。字体许可位于 `client/public/licenses/noto-serif-sc-OFL.txt`；勾选框由样式绘制，避免系统 emoji 改变外观。

导出 iframe 显式写入 HTML doctype，保持标准模式，并固定打印视口。表格显式继承字体；html2canvas 的二次克隆按节点标识冻结已解析的字号、字重等属性，再等待克隆字体就绪，防止兼容模式或移动端文字放大造成预览与 PDF 差异。底部门店地址和电话使用与正文一致的 9.5pt 常规字重。打印日期使用中文 DatePicker 与中文日期库语言包，输入框固定显示 `YYYY-MM-DD`，不依赖手机原生日期控件的语言设置。

打印设置提供“打印签字”是/否单选，默认是。选否时预览、系统打印及导出 PDF 均保留空白用户签字栏，不读取签名文件；仅影响本次打印，不修改已存签名。重新打开打印设置恢复默认。
