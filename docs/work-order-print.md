# 委托单打印

在“归档查询”打开“委托单详情”，点击“打印委托单”，预览后选择“打印 / 另存为 PDF”。建议使用电脑浏览器，在系统打印窗口选择 A4 纵向并关闭浏览器自带页眉页脚；可选择实体打印机或保存为 PDF。钉钉 WebView 的系统打印能力由客户端支持情况决定。

打印版按提供的《机动车修理委托书》纸质模板重建，使用当前详情中已保存的车辆、客户、接车检查、故障、维修项目、费用、顾问及门店信息。OCR 结果应先保存到委托单，打印不会另外读取未保存的识别结果。

客户手写签名放在“用户确认”处，优先使用 `signatures` 中客户签字关联的文件 ID；只有旧数据缺少关联且仅有一张签名图片时，才使用该唯一图片。签名缺失或加载失败时不能打印已签字委托单，避免生成漏签版本；未签字委托单标注“未签字”。“用户接车确认”栏已移除，服务顾问、总检验员栏保留。

常规记录保留九行维修项目；超出九行或内容较长时自动分页，维修项目表头在续页重复，用户确认和签名保持在同一块中。不输出来源照片的纸张颜色、扫描水印和复写联标记。物品勾选仅表示已登记的随车物品，不推断功能正常与否；轮胎深度、外观损伤坐标等未采集数据不会自动填写。
