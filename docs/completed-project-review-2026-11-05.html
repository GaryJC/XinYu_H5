完工核对复查

2026年11月5日

本人项目已通过检验，即使同单其他维修工尚未完成、整单尚未完结，也计入本人对应月份的完工清单。

已修复的问题

  • 历史项目只有整单完工日期时，待结算阶段新增项目会清除日期，导致原项目漏计或移到新月份。现在新增前保留已知原完工日期，后续完成新增项目时原项目仍归原月份。
  • 外包项目逐项完工时，原来依赖整单完成日期，可能延迟统计或归错月份。现在使用项目自身完工日期。
  • 历史单的维修员工数组为 null 时，数据库筛选与业务层回退规则不一致，单人项目可能漏计。现在两层都回退到已记录的单个维修工。
