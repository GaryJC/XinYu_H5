# 已提交委托单照片更新

在归档详情和已提交开单查看页，直接在原照片位置重新上传。行驶证、车身前后45度、仪表盘和额外照片可更新；其他照片可添加或替换。没有照片时显示上传入口。选图后自动保存并刷新对应位置，失败时保留原图并显示原因。草稿继续使用开单页面原来的保存流程。

仅本门店管理员和负责该单的服务顾问可操作，服务端在锁定委托单后再次校验归属。接口 `POST /api/work-orders/:id/photos` 仅接受照片类型、已上传文件 ID 和可选的被替换文件 ID；拒绝签名文件、其他单据附件和其他用户未关联文件。文件关联、当前照片位置、更新时间及审计记录在一个 PostgreSQL 事务内提交。替换后的旧文件保留，归档照片列表只展示当前图片；额外照片替换保持原位置。

仅更改照片元数据，不重新 OCR，不改已签字正文、签名、维修进度和润丰推送任务。不开放已提交委托单的通用编辑权限。本功能使用现有 JSONB inspection 字段，无新增数据库结构。


草稿行驶证上传先保存 `inspection.vehicleLicenseFileId`，与 OCR 是否成功无关。创建和保存草稿时，服务端使用同一事务校验并关联该图片和已有 OCR 记录；关联失败则回滚保存。客户端在上传/识别过程中拒绝保存或发起签字，避免先提交后上传完成。重新打开草稿优先恢复已保存的图片 ID，不依赖 OCR 结果。旧生产环境中已经脱离委托单的历史附件不会按上传时间或车牌自动猜测归属。


额外照片和其他照片支持从相册多选并依次上传，上传期间锁定整批操作，避免手机 WebView 同时处理多张大图。部分上传失败时保留成功照片，并提示成功数量及重新选择剩余照片。行驶证、车身前后 45 度及仪表盘仍按各自位置单张上传。

新建页的纸质委托书照片、额外照片，以及已提交单据的额外照片、其他照片提供勾选、全选和删除所选。已提交照片也支持单张删除。删除接口为 `DELETE /api/work-orders/:id/photos`，请求体 `{ fileIds: string[] }`，每次最多 100 张；使用与上传相同的门店及顾问权限，拒绝签名、维修任务照片、其他单据和已隐藏的照片。整批删除在同一事务内完成，校验失败不会部分删除。删除只移除当前照片引用并加入 `inspection.replacedPhotoIds`，原文件保留供追溯，记录操作留痕。纸质委托书至少保留一张照片，需要先补传再删除最后一张。

归档行驶证与其他照片使用紧凑卡片展示，手机端双列，点击缩略图查看原图。标题区统一提供添加入口，每张照片的“照片操作”菜单提供更换和删除；其他照片的“管理”模式提供全选及批量删除。上传与删除期间锁定所有相关操作，保留失败提示和服务端原有权限校验。
