# 仓管检索润丰配件

仓管在配件申请详情、管理员在维修任务详情中使用“润丰仓库检索”。点击维修工填写的配件名称直接检索，也可输入名称、货号、规格、厂家、车型、拼音码或参考编号；最多 80 字、6 个空格分隔关键词，各关键词都必须命中配件档案中的至少一个字段。

默认只查有结存的配件，支持取消库存筛选及按“部门／仓库”筛选。同名配件库按润丰仓库记录 ID 区分，部门和仓库名称同时显示，不会把不同部门的配件库混为一库。精确货号优先，随后是精确参考编号／品名及有结存的候选；一次最多显示 30 个配件，超出会提示缩小范围。

结果显示润丰货号、品名、规格、厂家、车型、参考编号、单位及分仓货位和结存数量。复制按钮支持普通 HTTP 页面及旧版钉钉 WebView 的剪贴板降级。复制润丰货号后可在润丰中快速查找；结果是候选档案，型号、单位和适用性仍由仓管核对，查询不预留配件、不写入润丰、不自动开出库单。

## 数据来源

已通过只读目录与样本查询确认 SQL Server 2000 字段：

- `dbo.hpxxb`：`hh` 货号，`pm` 品名，`gg` 规格，`sccj` 厂家，`cx` 车型，`jldw` 单位，`pym` 拼音码，`itemcode` 参考编号，`tybz` 停用标记；停用档案不参与检索。
- `dbo.cskcb`：`hh` 配件货号，`bm` 部门，`ck` 仓库名称，`hw` 货位，`jcsl` 结存数量。按部门、仓库、货位汇总；没有记录与零数量分别展示，不使用含义不同的 `dqkc` 替代。
- `dbo.ckxxb`：`reid` 仓库记录 ID，`bm` 部门，`mc` 仓库名称，`qybz` 启用标记。筛选条件同时匹配 `bm` 和 `mc`。
- `dbo.bmxxb`：`bm` 部门编码，`mc` 部门名称。

只读取当前配置的润丰数据库；不维护本地库存副本、不返回成本和售价。未配置或连接失败返回明确错误，不回退到示例库存。查询时间显示在结果中，实际数量以润丰出库时为准。

## 接口与权限

- `GET /api/dispatch/tasks/:orderId/parts-stock/warehouses` 返回启用仓库列表。
- `GET /api/dispatch/tasks/:orderId/parts-stock?query=...&warehouseId=...&inStockOnly=true` 检索配件及分仓结存。

仅有效仓管和管理员可以使用，沿用本店工单访问权限；工单需已签字且有当前或历史配件需求。检索不会改变任务、配件申请、备料或出库状态。共享响应契约在 `shared/types.ts`；SQL 在独立仓储模块，鉴权和输入验证在服务模块，页面交互状态在专用 hook 中。本次无数据库结构变更。

## 验证

单元测试覆盖输入边界、角色与门店权限、参数绑定及 LIKE 通配符转义、SQL Server 2000 语法、分页截断、同名仓库区分、货号大小写与零／未知数量。HTTP 集成测试覆盖未登录、越权、无效输入和未配置润丰时的明确错误。另以只读查询验证真实润丰仓库列表、模糊名称、精确货号及指定部门配件库筛选。完整检查使用 `npm run check`。
