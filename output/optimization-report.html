稳定性与性能优化验收记录

本地监测复验、完整 Chrome 流程、数据库故障和隔离 PM2 验收已补齐；用车照片处理按要求暂缓。

第一批：统计正确性与操作恢复

  • 个人返工按本人项目退回证据及轮次统一判定，列表、计数、排序、卡片共用规则。
  • 外包完工不等于内部检验；保留已检验项目和有证据的历史归属。
  • HTTP 支持取消与超时：读取 20 秒、提交 60 秒、图片/OCR/导出 120 秒，涵盖响应体读取。超时显示结果待确认，不自动重放。
  • 应用及功能区错误边界提供点击恢复，不自动刷新编辑页面；提交成功后的刷新失败独立反馈，保留已保存工单。

第二批：请求与数据库开销

  • 详情模式关闭隐藏列表、个人计数和负荷汇总；重叠刷新合并，过期读取可取消，移动端保留加载页。
  • SQL 只下推安全公共条件。复杂状态、权限、仓库申请展开、排序及分页仍遵循领域规则。
  • 归档摘要使用独立类型及显式 SQL 字段，详情/历史/签字/打印按需读取。
  • 项目保存改批量 UPSERT；会话和用户鉴权合并查询；钉钉 access token 合并并发获取。
  • 用车照片事务前处理暂缓，未覆盖另一聊天的用车流程改动。

第三批：移动端与运行保障

  • 归档交互、桌面表格、供应商报告延迟加载；缩略图临近视区加载，原图预览最多保留三张。
  • 连接等待 5 秒，交互事务锁等待 3 秒、SQL 15 秒；润丰写回事务豁免；回滚失败保留原始异常。
  • 模板化耗时日志、异常全量/正常抽样、关键队列最老任务年龄与连接池指标。
  • 停机先停止领取再排空，应用 60 秒、PM2 70 秒；独立 PostgreSQL 发布检查缺环境或出现跳过即失败。
