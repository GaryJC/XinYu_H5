已修复的问题

同店同名员工的工单权限

在新建工单上，服务端记录登录员工的账号 ID。草稿编辑、删除、现场签字、远程签字确认、照片和客户资料更新，以及给经办人发送的通知和待办，都以该账号识别人。同名同事无法代办，原经办人改名后仍能处理。纸质单由另一名顾问接手时同步更新经办人姓名和 ID。

换牌车辆录入

单独扫描车牌或车架号时，查询润丰会同时携带表单里的另一项标识。两者与档案不一致时保留输入并显示冲突原因。保存行驶证识别记录期间手动修改或清空的标识也会保留。识别结果缺少所属单位时，保留原单位编码。

客户签字时的维修清单

原先只有待客户确认项目的工单可以发起签字，但现场和远程页面都可能展示空清单。两处现按同一规则展示项目名称和状态，提醒客户哪些维修仍需另行确认。公开签字页面只收到展示所需字段。

配件申请和个人待办

纯仓管与兼任仓管的员工统一按待备料和部分备齐的申请计数。打开待办时会进入配件申请页，同一工单有多位申请人时，所选申请排在最前。

追加维修和检验通知

原单已待结算或完成、追加维修仍在进行时，检验待办按当前维修任务纳入。检验员曾代办外包开工、完工，仍可检验追加的店内项目。其他技师提检或提交回审时，有资格的原领取人保留任务。原领取人已停用、调店或失去资格时，任务重新开放领取。管理员可以保留有效领取，检验通知按收件人的检验员身份发送。

工单详情的只读权限

归档和详情使用同一读取规则。获授权的跨店纸质单收件人、已分配的技师和已领取的检验员可以打开列表里的对应工单。测试分别核对了详情、签字凭证和编辑权限。

车辆铭牌及配件照片

通用开单上传接口只接收公开的上传字段。铭牌照片须经过维修任务的人员、状态和轮次校验。仓管通过岗位共享读取铭牌或配件照片时，照片必须已关联符合条件的委托单。

历史工单归属

业务方已确认同店经办人不会重名。仅存姓名的旧单继续按同店经办人姓名匹配，新单按员工账号 ID 匹配。
